# ふたりの行きたい場所(Firebase版)

TikTok などのURLを貼るだけで、店名・住所・サムネイルが自動で入る2人用の共有アプリです。

## しくみ

1. 画面でURLを貼ると、サーバー関数 `/api/parse` を呼びます
2. サーバーは短縮URLをたどり、TikTokの公開oEmbedからキャプションを取得します
3. Gemini API(または Claude API)でキャプションから店名を抜き出します
4. Google Places API で住所と地図リンクを探します
5. 結果をフォームに入れます。2人のデータは Firestore に保存され、リアルタイムに同期します

APIキーを入れなければ 3・4 は飛ばされ、キャプションがメモ欄に入るだけになります。

## 画面

- **ホーム**:「👫 ふたりで共有」と「🔒 自分だけ」を切り替えて一覧を見ます。自分だけの場所は、相手には見えません(Firestoreのルールで本人以外は読めない領域に保存)
- **マップ**:場所の座標にピンを立てた地図です(OpenStreetMap + Leaflet。追加のAPIキーは不要)。ピンを押すと詳細が開きます。座標がない場所は地図に出ません(追加時に「検索」を押すと座標が入ります)
- **＋(追加)**:URLの読込、場所名からの検索(住所・座標)、カテゴリ、共有/自分だけの選択
- **思い出**:「行った!」にした場所を月ごとに表示。日付とリアクションを記録できます
- **設定**:名前、招待リンク、スペースを抜ける

## 対応状況

- TikTok:URLだけで取れます(公開投稿)
- YouTube:動画タイトルを取得します
- Instagram / Lemon8:ページ情報から取れることもありますが、ブロックされることが多いです

## セットアップ手順(PCで作業)

### 1. 準備
- Node.js(LTS版)をインストールします
- ターミナルで `npm install -g firebase-tools` を実行し、続けて `firebase login` を実行します

### 2. Firebaseプロジェクトを作る
1. https://console.firebase.google.com で「プロジェクトを追加」をクリックします
2. **Authentication** → 始める → ログイン方法で「**Google**」を有効にします(プロジェクトのサポートメールは自分のアドレスを選びます。無料です)
3. **Firestore Database** → データベースを作成します(場所は asia-northeast1 など)
4. **プロジェクトの設定** → マイアプリ → ウェブアプリ(</>)を追加し、表示された `firebaseConfig` の値を `public/index.html` の「ここに貼る」部分にコピーします。`authDomain` も、コンソールに出た値(○○.firebaseapp.com)のまま使います
5. **料金プランを Blaze(従量課金)に変更します**。サーバー関数(Cloud Functions)に必要です。2人で使う程度なら無料枠に収まる見込みですが、念のため Google Cloud の「予算とアラート」で月500円などの通知を設定しておくと安心です

### 3. APIキーを入れる(任意)
`functions/.env.example` を `functions/.env` という名前でコピーし、キーを書きます。
- `GEMINI_API_KEY`:https://aistudio.google.com/apikey で発行します(無料枠あり。無料枠で送った内容はGoogleの改善に使われることがあります)。Claude API を使いたい場合は、代わりに `ANTHROPIC_API_KEY` を入れます(従量課金)
- `GOOGLE_PLACES_KEY`:Google Cloud コンソールで「Places API (New)」を有効にし、APIキーを作ります。キーの制限で Places API だけに絞っておくと安全です

### 4. デプロイ
このフォルダで次を実行します。

```
cd functions && npm install && cd ..
firebase use --add        # 作ったプロジェクトを選ぶ
firebase deploy
```

最後に表示される `https://<プロジェクトID>.web.app` があなたのアプリです。

### 5. 使い方
- iPhoneのSafariで開き、共有 →「ホーム画面に追加」でアプリのように置けます
- 「新しく作る」で2人用スペースを作り、下の招待リンクを彼女に送ります
- TikTokで 共有 →「リンクをコピー」したら、URL欄に貼るだけで自動で読み込みます

## 注意
- ログインは「Googleアカウント + 招待リンク」です。招待リンクを知っていて、Googleでログインした人は誰でも「ふたりで共有」を見られるので、他人には送らないでください
- Googleでログインしているので、スマホを変えても同じアカウントでログインすれば、「自分だけ」のデータも戻ります。2人とも別々のGoogleアカウントでログインしてください
- サムネイルは、TikTok側の画像URLを使っています。時間がたつと表示されなくなることがあり、その場合はカテゴリのアイコンに切り替わります
- 地図のタイル(OpenStreetMap)は個人利用の範囲での使用を想定しています。大勢で使うなら、有料の地図サービスに切り替えてください
